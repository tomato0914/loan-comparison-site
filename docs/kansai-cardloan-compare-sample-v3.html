How to choose

かんたんな選び方

「どれが合う？」の目安です。最終判断はご自身で。

✓
とにかく急ぎたい口座がなくても申し込めて、契約日に借りられる可能性がある「南都クイックタイプ」。
✓
大きく借りて金利を抑えたい限度額が大きいほど金利が下がる「南都スマート」「京都ダイレクト」。
✓
安定収入で低金利がいい年収400万円以上・勤続2年以上なら、低金利の「MaxV」が候補。

金利や条件は、変わることがあります。

申し込みの前に、必ず各行の公式サイトで最新の内容をご確認ください。

ご利用にあたって
金利・限度額・条件は変わることがあります。最新・正確な情報は、必ず各行の公式サイトや窓口でご確認ください。 本サイトは情報提供が目的で、特定のローンの契約をおすすめするものではありません。実際に適用される金利や限度額は各行の審査で決まります。返済のことを考えた、計画的なご利用をおすすめします。 （MaxVの金利は変動金利のため、掲載値は目安です。）
